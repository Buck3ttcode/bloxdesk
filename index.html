BloxDesk Documentation

Roblox anti-cheat incident logging, automated AI appeal triage, and instant cross-server Open Cloud ban management.

Project Credits

BloxDesk is architected by @bucketcode on Discord and @buckettcode on Roblox.

Introduction

BloxDesk links Roblox game servers, Discord moderation staff, and Google Gemini AI into a synchronized security mesh. When suspicious physics activity occurs inside a running game session, server-side velocity, network ping, and assembly states are recorded without impacting server framerate.

When a banned player submits an appeal in your server's #appeal_channel, the triage engine evaluates their written statement directly against the recorded physics evidence and provides staff with a clear verdict:

  • Confirmed Violation: The telemetry mathematically disproves the player's claim (e.g. sustained 142 studs/s horizontal movement with 0% packet loss).
  • Innocent Glitch / False Ban: The telemetry confirms high-impulse explosion flings, vehicle glitches, or sudden server desync.
  • Manual Staff Review: Edge cases where telemetry is absent or ambiguous, presented to staff with 1-click Approve and Deny buttons.

License & Tier Requirement

In-game telemetry receipts require an active PRO or PRO+ subscription. The SDK automatically verifies your game's Universe ID on startup. If dropped into an unlinked game or a server on the Core plan, the SDK automatically disables itself at runtime and drops ingestion to prevent unauthorized telemetry or database pollution.

In-Roblox SDK Installation Guide

Follow these steps to set up BloxDesk inside Roblox Studio:

  1. Open your place in Roblox Studio.
  2. In the Explorer window, navigate to ServerScriptService.
  3. Drag and drop BloxDesk.rbxmx directly into ServerScriptService. The Explorer hierarchy will display:
    ServerScriptService → BloxDesk (ModuleScript)
  4. Enable HTTP Requests: Go to Home → Game Settings → Security and toggle Allow HTTP Requests to ON. Save changes.
HTTP Requests Required

BloxDesk requires HttpService.HttpEnabled = true to transmit incident telemetry and verify server configurations.

Initialization Script

Create a regular Script inside ServerScriptService named BloxDeskInit:

ServerScriptService/BloxDeskInit.server.luau 
local ServerScriptService = game:GetService("ServerScriptService")
local BloxDesk = require(ServerScriptService:WaitForChild("BloxDesk"))

-- Zero configuration required!
-- Automatically connects to the BloxDesk network using your game's Universe ID.
BloxDesk.Init()

print("[BloxDesk] Watcher running and monitoring players.")

For custom experiences (like Flying games or Speed Simulators), you can optionally pass a genre preset:

Optional Genre Preset 
BloxDesk.Init({
    Genre = "SpeedSimulator" -- Options: "Standard" | "SpeedSimulator" | "Flying" | "Racing"
})

Luau API Reference

The BloxDesk module exposes dedicated functions to handle gameplay exceptions, portal teleports, and custom anticheat hooks:

Luau API Methods 
-- Whitelist player capabilities (e.g. VIP flight gear, super-speed potions)
BloxDesk.SetPlayerCapability(player, {
    CanFly = true,
    InfiniteSpeed = false,
    CanTeleport = true,
    CustomSpeedMultiplier = 2.5
})

-- Whitelist a legitimate game teleport (portals, cutscenes, elevators)
-- Grants a grace window in seconds so teleportation does not trigger a false flag
BloxDesk.WhitelistTeleport(player, 5.0)

-- Monitor a RemoteEvent against script injector spam
BloxDesk.MonitorRemote(ReplicatedStorage.Remotes.AttackEvent, 25)

-- Manually log a staff ban to Discord with real-time physics snapshot
BloxDesk.LogBan(player, "StaffModerator", "Fly exploit detected during raid")

-- Report a custom incident flag
BloxDesk.ReportIncident(player, "CombatMismatch", {
    DamageDealt = 9999,
    MaxAllowed = 150
})

Discord Bot Setup Wizard

Running /setup in your Discord server initiates the 3-phase configuration process.

Phase 1: Channel Provisioning

BloxDesk automatically builds a clean Discord category containing:

  • #appeal_channel: Public player appeal submission channel with guided modal prompt.
  • #moderation: Private staff review queue showing evidence embeds and action buttons.
  • #bloxdesk_mod: Audit log recording all bans, unbans, and staff activity.

Phase 2: Universe ID Linking

Enter your Roblox Universe ID (Experience ID). BloxDesk queries Roblox APIs, verifies the experience exists, and retrieves its official game name for confirmation.

Phase 3: Roblox Open Cloud API Key

Generate an API key in the Roblox Creator Hub with User Restrictions (Read & Write) permissions. BloxDesk performs a live permission check, encrypts the credentials using AES-256-GCM, and displays the setup completion confirmation.

Staff Slash Commands

Command Parameters Description
/setup None Launches the 3-phase interactive onboarding wizard.
/lookup user: string Displays a player's rap sheet, previous appeals, active Open Cloud bans, and alts.
/history user: string Retrieves incident records with physics velocity vectors and ping history.
/license key: string Activates a commercial subscription tier (Pro or Pro+).

Triage Verdicts & Confidence

Rather than obscure technical jargon, BloxDesk produces clear, actionable verdicts in moderator channels:

Verdict Meaning Recommended Action
Confirmed Violation Telemetry mathematically proves active exploiting, prompt injection, or cheat recidivism. Deny Appeal & Maintain Ban
Innocent Glitch / False Ban Evidence confirms vehicle fling, physics collision impulse, or server-side lag spike. Approve Appeal & Lift Ban
Manual Staff Review Ambiguous claim or unmonitored incident requiring human moderator judgment. Staff Review Required
